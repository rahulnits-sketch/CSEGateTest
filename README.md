# GATE CSE Test Series 🚀

A modern online test series platform for **GATE Computer Science & Engineering (CSE)** preparation. The platform allows students to explore tests, view test details, attempt MCQ-based exams, and track their performance.

### ✨ Features

* 📝 Online GATE CSE mock tests
* 🎯 Topic-wise and subject-wise questions
* ⏱️ Timed test interface
* 📊 Test results and performance tracking
* 📚 MCQ-based question system
* 🔐 API-based question management
* 📱 Responsive and modern UI
* ⚡ Built with Next.js for fast performance

### 🛠️ Tech Stack

* **Frontend:** Next.js, React, TypeScript
* **Styling:** Tailwind CSS
* **Backend:** Next.js API Routes
* **Database/API:** Extensible API-based architecture
* **Version Control:** Git & GitHub

### 🎯 Goal

To build a simple, scalable, and user-friendly platform that helps GATE CSE aspirants practice regularly, identify weak areas, and improve their exam preparation.

### 🚧 Project Status

Currently under active development. More features such as authentication, analytics, leaderboards, additional test categories, and advanced performance tracking will be added progressively.
